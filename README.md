This Power BI visualization provides an interactive analysis of sales performance across US regions, 
showcasing key metrics such as total sales, Profits, Quantity Sold, region-wise sales in mao, and 
customer segmentation. It enables users to identify high and low-performing regions, analyze seasonal 
trends, and explore profitability insights. With interactive filters and tooltips, the dashboard supports 
data-driven decision-making for optimizing sales strategies and resource allocation.
